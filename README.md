# ONNX ROS Workspace

This project is a ROS (Robot Operating System) catkin workspace that integrates ONNX-based visual emotion recognition with speech interaction. It combines camera-based inference, speech recognition, and language model–driven responses into a single ROS package.

## Overview

- **Build system:** ROS catkin (CMake-based)
- **Main package:** `onnx_camera_recognition`
- **Key capabilities:**
  - Real-time camera image processing using an ONNX model
  - Emotion or category recognition based on `labels.txt`
  - Speech interaction pipeline driven by recognized results
  - Embedded Vosk English speech recognition model

The workspace is organized in a standard catkin layout, with build artifacts under `build/` and source packages under `src/`.

## Top-Level Structure

At the root of `onnx_ros_ws`:

- `.catkin_workspace`  
  Marks this directory as a catkin workspace.

- `.vscode/`  
  Editor configuration (e.g., C/C++ settings and workspace preferences).

- `build/`  
  CMake and catkin-generated build artifacts, including:
  - `CMakeFiles/` – CMake metadata, compiler checks, and test targets.
  - `catkin_generated/` – catkin-specific configuration, setup scripts, and ordered package information.
  - `gtest/` – Google Test support files used by catkin’s testing infrastructure.
  - `onnx_camera_recognition/` – build outputs related to the `onnx_camera_recognition` package.

- `src/`  
  Source code for all catkin packages in this workspace. Currently includes:
  - `onnx_camera_recognition/` – the main ROS package for ONNX-based camera recognition and speech interaction.
  - `CMakeLists.txt` – top-level catkin workspace CMake configuration (includes package-level CMake files).

Other build and configuration files at the root (e.g., `CMakeCache.txt`, `Makefile`, `catkin_make.cache`) are generated by catkin and CMake during compilation.

## onnx_camera_recognition Package

Path: `d:\onnx\onnx_ros_ws\src\onnx_camera_recognition\`

This is the core ROS package that provides the camera-based ONNX inference and speech interaction functionality.

### Package Metadata and Build

- `package.xml`  
  Declares the ROS package metadata, dependencies, and maintainer information.

- `CMakeLists.txt`  
  Package-level build configuration used by catkin to configure and build any nodes, libraries, or scripts.

### Launch Files

- `launch/onnx_camera_recognition.launch`  
  ROS launch file that orchestrates the package’s nodes and configuration.  
  Typical responsibilities:
  - Starting the ONNX inference node.
  - Configuring the camera topic (for example, `/usb_cam/image_raw`).
  - Launching the speech interaction node if needed.
  - Setting parameters for model paths and labels.

### Models and Resources

- `models/best1226.onnx`  
  ONNX model file used for visual recognition (e.g., emotion or category recognition from camera frames).

- `labels.txt`  
  Label list for the ONNX model, mapping model output indices to human-readable categories.

- `vosk-model-small-en-us-0.15/`  
  Embedded Vosk speech recognition model (English, US, small version).  
  Key subdirectories:
  - `am/` – acoustic model files.
  - `conf/` – configuration files such as `mfcc.conf` and `model.conf`.
  - `graph/` – decoding graph and associated resources.
  - `ivector/` – i-vector extractor and related configuration.

These resources enable local, offline speech recognition as part of the speech interaction pipeline.

### Python Nodes and Scripts

- `onnx_inference_node_gst.py`  
  ROS node that:
  - Subscribes to a camera image topic (e.g., `/usb_cam/image_raw`).
  - Runs ONNX inference using `best1226.onnx`.
  - Uses `labels.txt` to convert model outputs into readable labels.
  - Publishes recognition results, possibly including annotated images (e.g., to `/onnx_recognition/result_image`) and/or message topics for downstream nodes.

- `speech_interaction_ros_gst.py`  
  ROS node responsible for speech interaction:
  - Uses the Vosk model under `vosk-model-small-en-us-0.15/` for speech recognition.
  - Listens for events or results from the vision node to drive conversational responses.
  - Publishes or plays back synthesized responses (e.g., via audio output) based on recognized speech and the context provided by ONNX predictions.

- `gemini_worker.py`  
  Auxiliary worker script that likely:
  - Communicates with an external language model or cloud service.
  - Processes recognized text and context to generate natural language replies.
  - Integrates with `speech_interaction_ros_gst.py` as part of the conversation pipeline.

- `readme.txt`  
  Package-level text documentation (in plain text), possibly containing additional details or setup instructions.

## Build and Development Workflow (High-Level)

Although exact commands are not shown in the folder structure, the workspace follows standard ROS catkin conventions:

- Use a catkin build tool (e.g., `catkin_make`) from the `onnx_ros_ws` root to configure and build:
  - The `onnx_camera_recognition` package.
  - Any generated message or service code.

- Use ROS launch tools (e.g., `roslaunch onnx_camera_recognition onnx_camera_recognition.launch`) to:
  - Start camera recognition.
  - Run ONNX inference and speech interaction nodes.
  - Load model and label resources.

## Summary

This workspace provides a complete ROS-based pipeline that connects:

- A camera stream → ONNX-based visual recognition,
- Recognition results → speech interaction logic,
- Speech recognition (Vosk) → language model processing (via `gemini_worker.py`),
- And back to speech responses.
